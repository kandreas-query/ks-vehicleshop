Upload the vehicle image here as a transparent PNG named `<model>.png`.
Examples: zentorno.png, sultanrs.png, akuma.png

- Use a transparent PNG so no box or frame appears.
- The filename must match the vehicle's spawn code (lowercase).
- The PNG or catalog image is automatically assigned to the FiveM documentation entry.
- Alternatively, you can provide a specific URL for each vehicle using the "Image URL" field in the admin panel.
